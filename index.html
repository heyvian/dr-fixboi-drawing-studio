        Illustrator SVG

        Editable vector strokes, organized by pen weight and treatment.

        Create named layers in Illustrator
        1. Download the Illustrator script.
        2. Click Download SVG to save the drawing.
        3. In Illustrator, choose File → Scripts → Other Script and select the downloaded .jsx.
        4. When prompted, select the SVG you downloaded.
        5. Choose where to save the .ai file and click Save.

        Photoshop PSD

        Editable pixel layers grouped by pen weight, section treatment and annotation.

        Bluebeam PDF

        Download a vector PDF at the displayed sheet size for markup in Bluebeam Revu or another PDF reader.

        Print or save as PDF

        In the print dialog, select a printer or Save as PDF. Choose Actual size or 100% to keep the drawing scale.
