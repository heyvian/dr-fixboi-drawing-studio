Dr. FixBoi®’s

Drawing studio

I plot the lines.You bring the aura.

Dr. FixBoi gets the plans, sections, elevations and axonometrics out of your model and into Illustrator. I'll output the linework so you can add your special touch. Make those drawings have some rizz as they say.

Drop a .3dm or .obj file anywhere on the plate. Files are processed in your browser.

Controls

Move around the model to choose what to draw. Switching to Drawing uses this view as the starting point for the drawing; moving the drawing there never changes this view.

  • Drag orbit
  • Right-drag or Shift-drag pan
  • Wheel zoom to the cursor
  • Double-click set the orbit centre (or use Set orbit centre)
  • Arrows pan, + − zoom, Home extents
3D linework

Mesh edges are found from the model's triangles. Intersections between objects are not drawn.

Saved views

Layers

Untick a layer to leave it out of every drawing.

Line weights

Percent of the depth from the nearest to the farthest visible line. Lines nearer than the first threshold use the heaviest pen, lines beyond the second the lightest, and the pens share the span between.

Drawn edges

Use the heaviest pen on the model perimeter, or on each outline body chosen under Layers.

Widths stay fixed on paper at every scale.

Weights are in printed millimetres. Section cuts use the heaviest weight.

Clipping planes

SVG and Illustrator

Open the SVG in Illustrator for editable groups. To create named layers and save an AI file, run the script from File → Scripts → Other Script and select the SVG.
