        Create named layers in Illustrator

        1. Download the Illustrator script.
        2. Click Export to save the SVG.
        3. In Illustrator, use File → Scripts → Other Script and select the downloaded .jsx.
        4. When prompted, select the SVG you exported.
        5. Choose where to save the .ai file, then click Save.
